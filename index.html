How the Rs. 500 payments actually work

This page is the front end. Automated card checkout ("Buy" buttons wired to Gumroad/Stripe) isn't connected yet — but you can start taking money right now with manual JazzCash payments while you set that up.

  1. JazzCash (active now) — every Buy button shows your number and asks the buyer to send the amount, then confirm. You'll need to manually check JazzCash and unlock the tool/course for them once you see the payment.
  2. Gumroad — for automatic checkout later. Create a product for each tool/course, get a checkout link, paste it into the PAYMENT_LINKS object near the bottom of this file's script.
  3. Stripe Checkout — more control, needs a small backend (even a free Cloudflare Worker or Vercel function) to create the checkout session securely.

JazzCash gets you earning today with zero setup — just remember every unlock is manual until you add an automated link. Search YouTube for "Gumroad checkout link tutorial" when you're ready to automate.
